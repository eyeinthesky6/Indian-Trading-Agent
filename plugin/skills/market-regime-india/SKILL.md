# Market Regime

Regime is context, not a prediction.

Assess as available:
- Nifty/Sensex trend and volatility,
- sector/index relative strength,
- breadth/participation,
- volatility state,
- gap/event behaviour,
- single-security trend separately from broad market.

Labels should be simple: trending up/down, range/transition, high-vol transition. State evidence and invalidation.

A trend-following setup in a range requires extra justification; a mean-reversion setup in a clean trend should be treated cautiously. Do not create elaborate regime taxonomies that cannot be observed reliably.
