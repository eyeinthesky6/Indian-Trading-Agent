# Technical Analysis

Use indicators as measurements, not incantations.

## Core state

Prefer a compact set:
- price versus 20/50/200 structures as horizon warrants,
- 5/20-session momentum,
- RSI as momentum state, not automatic reversal,
- ATR / realised volatility,
- recent swing/20-session high-low,
- volume versus normal when volume data is reliable,
- relative strength versus relevant Nifty/sector benchmark when available.

Use multiple timeframes only when they answer a real question. Explain disagreement rather than averaging it away.

## Levels

A level should come from observable structure: prior swing, gap, range boundary, VWAP/anchored reference when data supports it, moving-average reclaim, or event level. Avoid invented precision.

## Output

Separate Observed / Calculated / Interpreted. End with what would change the technical state. Do not force a trade.
