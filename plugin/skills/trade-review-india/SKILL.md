# Trade Review

Judge the process using information available **at decision time**.

Review:
- was data fresh,
- was the regime/setup correctly described,
- did entry follow the planned trigger,
- was stop/invalidation respected,
- was size within risk constraints,
- did new evidence emerge after entry,
- what was MFE/MAE if data is available,
- was exit according to plan or improvised.

Classify outcome separately from process. A profitable rule violation is not automatically a good trade; a disciplined loss is not automatically a bad one.

Feed recurring process errors back into skills/risk controls, not into hindsight storytelling.
