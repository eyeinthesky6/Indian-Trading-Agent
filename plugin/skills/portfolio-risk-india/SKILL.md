# Portfolio Risk

Start with what can be measured reliably:
- gross exposure,
- net exposure,
- largest position,
- sector concentration,
- directional concentration,
- event/catalyst overlap.

If return histories are available, add correlation/cluster analysis carefully and state lookback. If not, use economic common-sense groupings and label them qualitative.

Before adding a candidate ask whether it duplicates an existing bet. A 1% risk trade can still be reckless if five positions all fail on the same RBI, crude, INR or sector event.
